# 🍳 CookCook

> 完全ローカル・オフラインで使える個人用レシピ／食事計画／食材管理 PWA。ホーム画面に追加すればアプリのように使え、データはすべて端末内に保存。サーバー不要・ログイン不要・通信不要。

「毎日何を食べるか」に悩む人のための小さなツール。レシピ、毎日の食事計画、食材の在庫・賞味期限、買い物リストをひとつのオフラインアプリにまとめたもの。スマホのブラウザでURLを開き→共有→ホーム画面に追加で使える。

## ✨ 機能

下部4つのタブ：

- **📅 カレンダー** — 週表示（月曜始まり、週末を見やすい）。日付をタップするとその日の食事ページへ。1日6スロット（朝食／朝間食／昼食／午後の間食／夕食／夜食）、レシピ追加も自由テキスト追加も可能。閲覧モードでは内容があるスロットのみ表示・サムネイル拡大、編集モードで追加・削除。
- **🍳 メニュー** — レシピ一覧（サムネイル＋タグ＋カロリー）、タップで詳細（画像・食材リスト・手順）。検索（料理名・食材の曖昧一致）、お気に入り ★、ピン留め 📌、作った ✓、5つ星評価。**並び替え**：デフォルト／追加日時／カロリー／食材数／名前／カテゴリ、ピン留めは常に優先。**タグ**：複数選択フィルタ＋カスタムタグ記憶、「作った」はタグのドロップダウンに統合。
- **🥫 食材庫** — 賞味期限ごとに4色分け（期限切れ／間もなく切れる／新鮮／期限なし）。2段フィルタ（期限状態＋カテゴリタグ）、タグ選択で該当グループを自動展開。
- **🛒 買い物** — カレンダーで期間を選択→全レシピの食材を集計→食材庫の在庫を引く→不足リストを生成。進捗バー＋未購入/購入済みの切替＋チェック。

### レシピの半自動インポート

ブラウザのCORS制限で全自動取得は不可能なため、**スクショ→OSのテキスト認識でコピー→貼り付け**の方式。テキストを貼ると構造化された食材（名前・分量・単位）と手順に自動解析。1行に複数食材のカンマ区切り、行内見出し、多種区切り文字に対応。画像選択・名前・保存を手動で行い一気に完了。

## 🛠 技術スタック

- **純粋バニラJS＋ネイティブCSS**、ビルド不要・CDN不要・依存ライブラリ不要。オフライン利用と静的ホスティングを保証。
- **IndexedDB**に全データ（画像Blob含む）を保存、自作の最小ラッパー。
- **PWA**：`manifest.json`＋`sw.js`（アプリシェルをキャッシュ、オフライン起動）＋アイコン。
- シングルページ、下部タブ＋ハッシュルーティング。
- **オフラインカロリー表**内蔵（`calories.js`、約150件の食材 kcal/100g または1個あたり）、単位感知＋個数からグラム推定。外部API不依存。

## 📁 ファイル構成

```
index.html        # アプリシェル＋4タブコンテナ
style.css         # モバイル優先スタイル
db.js             # IndexedDBラッパー
store.js          # データ操作 (recipes / plans / pantry / shopping)
import.js         # 貼り付けテキストの構造化解析
calories.js       # オフラインカロリー推定表
app.js            # ルーティング＋各タブ描画＋イベント
manifest.json     # PWA manifest
sw.js             # service worker（アプリシェルキャッシュ）
icons/            # 192 / 512 アイコン
```

## 📱 インストール方法

1. ブラウザで公開URL（GitHub Pages）を開く。
2. 共有→「ホーム画面に追加」。
3. ネイティブアプリのように開き、オフラインでも読み書き可能。

> iOSのPWA更新は遅い：更新後はホーム画面のアイコンを完全に終了してから再起動するか、ブラウザで直接URLを開いて強制リロード。コード更新のたび `sw.js` の `CACHE` バージョンを上げて更新をトリガー。

## 🔒 プライバシー

純粋なフロントエンドプロジェクト、バックエンドなし・.envなし・APIキーなし・第三者トラッキングなし。すべてのデータは自分の端末のIndexedDBにのみ保存され、外部に送信されない。

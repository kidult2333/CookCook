# 🍳 CookCook

> 纯本地、离线可用的个人菜谱 / 餐单 / 食材库管理 PWA。加到主屏幕像 app，数据全存手机本地，无需服务器、无需登录、无需联网。

一个为「每天要想吃什么」的人做的小工具：把菜谱、每日餐单规划、食材库存与保质期、购物清单都收进一个离线 app 里，手机 Safari 打开网址 → 分享 → 加到主屏幕即可使用。

## ✨ 功能

底部 4 个 tab：

- **📅 日历** — 周历视图（周一起，方便看本周周末），点某天进餐单页。每天 6 个餐次（早餐 / 早加餐 / 午餐 / 午加餐 / 晚餐 / 晚加餐），可加菜谱或自定义文本。查看态只显示有内容的餐次、放大缩略图；编辑态可增删。
- **🍳 菜单** — 菜谱列表（缩略图 + 标签 + 热量），点进看详情（图片、食材清单、步骤）。支持搜索（按菜名或食材模糊匹配）、收藏 ★、置顶 📌、做过 ✓、五星打分。**排序**：默认 / 添加时间 / 热量 / 食材种类 / 名称 / 类别，置顶永远优先。**标签**：多选筛选 + 自定义标签记忆，"做过"整合进标签下拉。
- **🥫 食材库** — 按保质期分 4 组配色（已过期 / 即将过期 / 新鲜 / 无保质期），双层筛选栏（过期状态 + 分类标签），选标签自动展开对应分组。
- **🛒 购物** — 从日历选日期范围 → 聚合所有菜谱食材 → 减去食材库已有 → 生成缺货清单。进度条 + 待购/已购分段 + 勾选。

### 小红书菜谱半自动导入

浏览器 CORS 限制做不到全自动抓取，采用**截图 → iOS 实况文本复制 → 粘贴**的方式：粘贴文本后自动解析为结构化食材（名称 / 数量 / 单位）+ 步骤，支持一行多食材逗号分隔、内联段头、多种分隔符。手动选图、命名、保存，一步到位。

## 🛠 技术栈

- **纯 vanilla JS + 原生 CSS**，无构建步骤、无 CDN、无第三方依赖 —— 保证离线可用 + 静态托管即可。
- **IndexedDB** 存所有数据（含图片 Blob），自写极简 wrapper。
- **PWA**：`manifest.json` + `sw.js`（缓存 app shell，离线可开）+ 图标。
- 单页应用，底部 tab + hash 路由。
- **内置离线热量表**（`calories.js`，约 150 条中文食材 kcal/100g 或每份），单位感知 + 按个数估算克数，不依赖外部 API。

## 📁 文件结构

```
index.html        # app shell + 4 tab 容器
style.css         # 移动端优先样式
db.js             # IndexedDB wrapper
store.js          # 业务数据操作 (recipes / plans / pantry / shopping)
import.js         # 粘贴文本解析为结构化菜谱
calories.js       # 离线热量估算表
app.js            # 路由 + 各 tab 渲染 + 事件
manifest.json     # PWA manifest
sw.js             # service worker (app shell 缓存)
icons/            # 192 / 512 图标
```

## 📱 在 iPhone 上安装

1. 用 Safari 打开线上网址（GitHub Pages 托管）。
2. 分享 → 「添加到主屏幕」。
3. 像原生 app 一样打开使用，离线也能读写数据。

> iOS 对 PWA 更新检查较懒：更新后需「杀掉重开」主屏图标，或用 Safari（非主屏图标）打开网址强制刷新。每次代码更新会升 `sw.js` 的 `CACHE` 版本号触发更新。

## 🔒 隐私

纯前端项目，无后端、无 .env、无密钥、无第三方追踪。所有数据只存在你自己的设备 IndexedDB 里，不离开本机。仓库公开是因为纯前端无隐私数据，公开安全。
